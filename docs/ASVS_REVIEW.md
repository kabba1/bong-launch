# ASVS working register

`asvs-5.0-l2-evidence.json` retains every Level 1/2 requirement from the official OWASP ASVS v5.0.0 versioned JSON. It maps available implementation/evidence and unresolved scope. It is a working review register, not certification. Proposed exclusions are not approved exclusions.

Source: [OWASP ASVS v5.0.0](https://github.com/OWASP/ASVS/tree/v5.0.0/5.0), [license](https://github.com/OWASP/ASVS/blob/v5.0.0/LICENSE.md). OWASP requirement text and this adapted register are provided under Creative Commons Attribution-ShareAlike 4.0. The adaptation adds BONG applicability, test references, status and gaps; OWASP has not reviewed or endorsed this implementation.

The independent reviewer must resolve every applicable control and sign off any narrow exclusions. Product choices expressly specified for BONG, including email-code member authentication, are not evidence that a stricter ASVS control is satisfied. Provider-managed responsibilities still need actual configuration/testing evidence. The production release gate remains blocked until the assessment is complete.
