# Historical generated-spec records

These files preserve the large generated specification's release/evidence process and later development reports. They contain stale candidate hashes, test counts, build IDs, approval requests, v1 matrices, earlier timeline requirements and publication restrictions. They are historical source material, **not current instructions or the definition of BONG v1 completion**.

The owner developed the current site through visual iteration and explicitly retired that framework for public v1. No archived failure has been changed to PASS, and no approval or reviewer has been invented. Original content is preserved for provenance; relative links inside historical documents may refer to their former locations or old local evidence.

Use [the current launch guide](../../V1_LAUNCH.md), not these records. Archived public acceptance/ASVS/release JSON is never read by the public release command. The explicitly separate [future Community-v2 framework](../../future-community-v2/README.md) may still inspect its original full matrices and pre-v1 report; these do not establish fresh evidence for private features.

README.original.md, AGENTS.original.md and release.test.ts.txt capture superseded instructions and assertions, not active project rules. Existing IDs on engineering tests remain useful labels without requiring the old spreadsheets.
